NamTranVoice là ứng dụng Desktop local-first dành cho tạo giọng nói đa ngôn ngữ. Chương trình có ba model TTS là Kokoro Vietnamese, VietNeu-TTS v3 Turbo và MOSS-TTS-Nano; hỗ trợ preset, clone giọng cho model tương thích, nhập TXT/SRT, nhập giọng nói tiếng Việt–Anh, CPU và DirectML GPU tùy chọn.
## Yêu cầu

Bản phát hành là Windows x64, không yêu cầu Python hay cài đặt thêm gì (Chỉ cần cài Microsoft Visual C++ Redistributable để Chạy nếu chưa có). Internet chỉ bắt buộc trong lần nhập KEY kích hoạt đầu tiên. Sau khi kích hoạt hợp lệ có thể sử dụng, KEY được lưu với 1 thiết bị, các lần khởi động sau app sử dụng được hoàn toàn offline.
